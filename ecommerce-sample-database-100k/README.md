# 电商零售智能决策：已核验数据源交付包

**用途：**《基于用户全生命周期的电商零售智能决策与 AI 运营助手系统》课程设计，可直接作为原始数据+历史分析样本+数据源说明+验收证据。

## 目录

- `01_source/`：原样保留你上传的原始 ZIP（未改动）；SHA-256 在 `quality_report.json`。
- `02_historical_utf8/`：截至 2026-11-07 UTC 完整日的 10 张 CSV，统一 UTF-8 BOM 编码，适合 Excel/Python 导入。
- `03_derived_demo/`：从完整历史订单重算的用户 RFM 观察窗口快照，仅供课程分析；没有生成虚构浏览日志。
- `04_audit/`：原始数据字典、合成数据运行元数据、数据质量报告。
- `DATA_SOURCE.md`：可直接修改后纳入选题报告的数据源说明。

## 已核验数量

- 原始订单：10,000 条；历史订单：9,311 条。
- 历史订单明细：15,639 条（满足 >= 10,000 条）；历史 10 表总行数：77,916。
- 用户：3,647；订单表字段：17；存在时间字段。
- 关键外键、订单创建时序、商品/上架时序、商品明细与支付金额对账：经本地实读核验，无对应异常。

## 重要限制

1. **完全合成的数据**：不能写成实际企业或真实顾客业务。
2. **不是浏览行为数据集**：没有真实浏览、加购和归因会话。选题的已证实研究范围为“首次可观测购买→活跃→复购→流失风险”；如果报告声称完整获客漏斗，需要另外取得同源行为数据。
3. **原始生命周期标签不可直接当真值**：使用历史购买事件和你们明确定义的规则重建。
4. **原始 ZIP 包含 2026-11-08 以后未来模拟订单**：这些订单仅保留在原始存档，分析用目录已剔除。
5. **指导书“2026 年 1 月后数据集”条款存在解释问题**：此包元数据中的生成日期为 2026-07-21T00:34:14+0000，但原始业务事件从 2024 年开始；不自动声称已获老师认可。

## 可复现

将 `build_retail_verified.py` 与原 ZIP 放在同一目录，运行：

```bash
python3 -m pip install pandas
python3 build_retail_verified.py --source baseline_10000_seed42.zip --out retail_baseline_verified
```

建议将本交付包作为 DATA-01～DATA-06 的已验证基础材料，但是否正式通过还应由团队检查并确认教师要求。
