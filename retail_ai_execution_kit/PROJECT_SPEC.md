# 项目规格与范围基线

基线日期：2026-11-05，时区Asia/Shanghai。目标是在2026-11-09、11-30、12-22完成课程三个阶段。内部功能冻结建议12-13，之后复现和演练；12-19至20不安排核心开发。

## 1. 交付目标

为电商零售运营构建可重建的数据处理、分层数仓、OLAP、生命周期/RFM、未来30天复购预测及三个AI模块，并由Streamlit承载交互。每个结论能回溯真实数据，每个完成状态有验收证据。
目前只提供执行与治理材料；不得据此声称已下载正式全量数据、建仓、训练模型、接通LLM或提交课程材料。

## 2. 范围级别

- 教师硬要求/评分依据：见project/requirements.json的C类；冲突由原件与教师明确解释裁定。
- 用户承诺：U类，包括ODS-DWD-DWS-ADS、星型、RFM/复购、三个AI模块、Streamlit。
- 工程验收：Q类，是本项目为可验证交付制定的质量条件，不冒充教师原文数值。
- 可选：B/X类，默认不启用。算法菜单不要求每种都做；普通完整项目不依赖微调LLM、GPU、Spark、实时Kafka、复杂微服务。

## 3. 数据选择尚未冻结

`project/tasks.json.active_dataset` 初始为空。交易候选Online Retail II需教师认可历史数据；行为候选Cosmetics同样为历史数据。T-ECD只有2026更新证据并不能证明2026事件，当前已查零售分片仅6列且缺金额。不要把这些候选写成已满足全部课程条件。
课程数据时效是D001阻断项。可以先做候选事实核验、接口与基础设施，正式数据符合性不能提前通过。
交易路线聚焦首次可观测购买后的生命周期；真实首购、注册、渠道获客和浏览漏斗仅在实际数据支持时加入。
原件、提取文本、样例分组均在sources；原件仅作课程使用，不自动纳入将来的公开仓库。

## 4. 默认技术路线

Python + Parquet/DuckDB + scikit-learn/LightGBM + Plotly/Streamlit + 一家实际可用LLM API。安装后锁依赖，记录平台；优先适配用户Mac ARM64，其他成员平台实际验证。不要求公网部署。
离线ETL/训练与在线只读查询分离。代码按职责划分data、warehouse、features、model、analysis、ai、ui；具体路径以任务输出和接口约定为准，合理调整记录后同步。

## 5. 数据与模型语义

交易金额、订单和取消规则先写进contracts。订单数不是商品行数，正向消费M不是利润或严格CLV。
默认预测样本是客户×as_of；母体为过去90天有有效购买的已知客户；标签为未来30天有效正向购买。未复购风险=1-复购概率。长期无购买用户使用规则队列。
训练/验证/测试按时间，标签成熟后才能用于后续阶段，测试只做最终评估。所有特征、退货、属性和预处理只用当时可得信息。生命周期规则、RFM聚类与预测风险独立呈现。
基线为R规则和逻辑回归，再比较LightGBM；以验证结果选择并冻结。没有最低AUC成绩承诺，真实负结果也必须报告。

## 6. AI系统边界

1. 查询助手：自然语言转受约束意图或SQL，可信执行后回答；使用指标语义和Schema白名单。
2. 诊断周报：SQL计算事实，模型解释，最终数字与引用再校验。
3. 运营Agent：读取画像与风险、检索政策、检查资格预算、保存草稿；没有真实营销发送权限。

RAG检索指标、模型卡与规则，结构化数据走SQL。缺失的触达、投诉、同意、库存和毛利必须标为演示配置。真实LLM集成和离线回放分别验收，不以预写答案冒充在线能力。

## 7. 确定性与验收

阶段就绪由scripts/project.py gate检查任务状态与证据完整性，再做业务审阅；脚本不能证明结论本身正确，更不能替代教师评分。
AI建议评测规模：NL2SQL≥40（其中≥24可答，结果正确率目标≥90%）、RAG≥20、周报≥20、Agent≥30；这些是项目质量目标。性能目标先测基线后冻结，不临时降低标准掩盖失败。
模型数值、收益与生产可用能力不得预填。收入/留存增量须真实干预证据；否则仅做标假设的情景测算。

## 8. 变更与协作

AGENTS.md管理工作方式；project/tasks.json为唯一任务状态，project/requirements.json为需求索引。TASKS/STATUS/REQUIREMENTS为生成视图。ops/DECISIONS.md保存决策，不另建相互冲突的“最新进度”。
先复用已有成果，按依赖推进可执行任务。常规可逆实现和修复自主完成；已授权操作不重复询问。需要外部凭据、课程歧义解释、改变已承诺范围或不可逆外发时才升级，并继续不受阻部分。
