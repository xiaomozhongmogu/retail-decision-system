# 模型卡：未来 30 天复购模型（`repurchase-logreg-v1`）

- 2026-11-10，claude-opus-5-5；清单 `reports/model/model_manifest.json`（模型文件 `models/repurchase-logreg-v1.json`，SHA-256 `01b2b335…55d2`）
- **数据完全合成**（合成电商交易包，D012/D013）；以下全部是实测结果，没有写入任何未取得的效果。

## 1. 用途

| 项 | 内容 |
|---|---|
| 预测什么 | 客户在 as_of 之后 30 天内是否有一次有效（已审批）购买；输出复购概率，未复购风险 = 1 − 概率 |
| 对谁 | as_of 前 90 天至少有一次有效购买的已知客户（`target-v1`）；其他客户返回 `out_of_population` |
| 可以用于 | 展示和汇总**平均**复购水平；作为周报、看板的背景信息 |
| 不能用于 | 挑选“最该联系的少数客户”、宣称识别高风险客户、估计营销挽回效果、真实企业或中国市场的决策 |

## 2. 数据与特征

- 样本：客户 × 每周一 as_of，2024-04-01 至 2026-10-05，共 92,241 行、3,312 名客户，正例 7.17%（`reports/model/sample_audit.json`）。
- 特征：30 个时点特征（`features-v1`，`docs/feature_dictionary.md`），只用 as_of 之前已可见的订单、送达和评价；已用“删除未来信息后重算不变”的测试验证。
- 切分：按 as_of 时间，训练 2024-04-01 至 2025-08-25、验证 2025-09-29 至 2026-02-23、测试 2026-03-30 至 2026-10-05，中间各留 5 周让标签成熟（`split-v1`）。

## 3. 模型

- 逻辑回归（C = 1.0，不加类别权重），训练期中位数填补、log1p、标准化；冻结版本用训练 + 验证共 68,682 行重拟合（ML-08）。
- 不做概率校准：时间分块交叉拟合下，Platt 与等渗校准都没有改善 Brier。
- 比较过的候选：规则（最近购买、近 90 天订单数）、类别加权逻辑回归、LightGBM（8 组参数）。LightGBM 在验证集上没有超过逻辑回归，保留更简单的模型。
- 周名单排序采用近 90 天订单数规则（ML-08），模型概率不用于排序。

## 4. 评估（测试集，只使用一次，`reports/model/test_metrics.json`）

| 指标 | 本模型 | 基率常数 |
|---|---:|---:|
| ROC-AUC（客户分块 95% 区间） | 0.515 [0.483, 0.546] | 0.5 |
| PR-AUC | 0.074 | 0.071 |
| 周内平均 ROC-AUC | 0.500 | 0.5 |
| 周内 Lift@10% | 0.84 | 1.00 |
| Brier | 0.06604 | 0.06595 |
| 校准误差 ECE | 0.008 | — |

结论：平均水平可信（ECE 0.008），但个体区分能力与随机相当，置信区间包含 0.5。这是诚实的负结果，没有为此更改目标或测试集。

## 5. 限制

- 原因：30 天内再次购买的间隔只占约 11%；母体内外、各生命周期状态的复购率几乎相同（`docs/model_target.md`、`docs/lifecycle_rules.md`）。合成生成器中复购与历史行为关系很弱。
- 测试集 74% 的客户也出现在训练集：结果只说明已知客户在未来时点的表现，不证明对全新客户有效。
- 系数和“主要因素”是模型如何组合特征的描述，不是因果效果（`reports/model/error_analysis.md`）。
- 没有触达或实验数据，模型不估计营销增量。

## 6. 版本与维护

- 加载：`src/retail_bi/model/scoring.py` 的 `load_model()` 校验模型版本、特征版本和特征顺序，`score_frame()` 打分；顺序、类型或版本不符会报错（ML-11 测试）。
- 复现：新进程加载模型，对 `reports/model/model_fixture.json` 中固定的 20 个测试样本重新计算特征并打分，与登记概率的最大差 2.8e-17（容差 1e-9）。
- 评分作为流水线阶段写入 `ads.model_scores`，构建版本包含模型文件哈希；换模型需要新版本号、重跑 ML-06 至 ML-09 并更新本卡。
- 建议在新数据上至少每季度用同一切分规则重新评估；如果数据换成真实交易，需要重新冻结目标（ML-01）。
