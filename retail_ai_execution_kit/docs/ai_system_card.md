- 版本 v2，2026-11-13，claude-opus-5-5（v2：按外部 AI 测试修复后更新）；统一入口 `src/retail_bi/ai/integration.py`
- 数据：完全合成的电商交易数据，发布版本 `wh-d3aaa559048c`，as_of 2026-11-08（不含）；指标口径 `metrics@e84d17c3`；知识库 `kb-v1`；挽回政策 `retention-policy-v1`（演示配置）
- 模型：DeepSeek（OpenAI 兼容接口；请求 `deepseek-chat`，接口返回 `deepseek-flash`）；密钥只在本地 `.env`

## 1. 三个模块

| 模块 | 课程方向 | 输入 → 输出 | 模型做什么 | 程序保证什么 |
|---|---|---|---|---|
| 查询助手 | ①智能数据分析助手（NL2SQL） | 中文经营问题 → 答案、结果表、SQL 与证据 | 规则无法识别时解析意图；补一句不含数字的口径提示 | 问题先转成结构化意图并过目录校验；问题中出现而意图没有用上的条件（品类、大区、季度、日期、周、多个年份、“平均”）一律要求澄清，不回答更宽泛的问题；只执行可信查询计划；在只含允许视图的沙箱中只读执行；答案数字由程序生成 |
| 经营周报 | ⑤自动化报告生成 | 当周事实 → 带引用的周报 | 写解释、行动建议、待验证假设，数字只用占位符 | 事实由代码计算；占位符由程序填值；多条规则校验（数字、单位、因果、不存在字段、不完整期间、截止日）；修复最多 2 次，失败回退模板；最终数字复核 |
| 挽回 Agent | ③智能决策 Agent / ⑥营销文案 | 客户编号 + 演示配置 → 待审草稿 | 参考规则引擎给出的价值层级与折扣上限，在限定选项内提议动作；写文案 | 固定工作流、最多 8 步、5 个工具；资格、折扣、频率、预算由规则引擎决定；文案不得声称已发送或已发放，提醒不得提优惠，优惠只能写本次批准的百分比（人工修改也适用）；草稿幂等（含并发）、只能待审，没有发送或发券能力 |

## 3. 运行模式与降级

| 模式 | 触发 | 查询助手 | 周报 | Agent |
|---|---|---|---|---|
| live | 有密钥且允许付费，模型返回可用结果 | 规则意图 + LLM 口径提示 | LLM 解释（校验通过） | LLM 提议与文案 |
| fallback_no_key | 没有密钥或未授权付费 | 规则意图，无提示 | 可信模板 | 规则默认提议 + 模板文案 |
| timeout / rate_limited | 网络超时或 429（有限重试后） | 同上 | 同上 | 同上 |
| replay | 回放已记录的 LLM 周报文本 | — | 醒目标注“不是本次真实调用” | — |

每次运行写一条事件到 `logs/ai/events.jsonl`（不提交）：模块、模式、结果、耗时、本次调用次数、token 与估算费用、工具步骤（含每步耗时）、证据编号、错误与版本。日志不含密钥、提示原文或客户明细行；客户编号以短哈希记录；调用日志中的错误信息同样脱敏。只有模型输出确实被采用时才记为 live。

## 4. 没有覆盖的边界（如实说明）

- **数据**：完全合成数据，教师尚未确认可作为课程主数据；同意、投诉、触达、库存、毛利、预算均为演示配置。
- **模型效果**：复购模型测试 ROC-AUC 0.515，个体区分接近随机，只作平均水平参考。
- **问答**：规则解析只覆盖文档列出的约 15 类问题；标准集分数是看到失败后修复的结果。对全新问法的表现应看两次首测：我方标准集 85.7%，Gemini 独立出题 80%（修复后的 92% 同样是看到失败后才修的）。不支持：取消订单金额、按品类或大区分组的同比/环比、按周同比。
- **语义正确性**：代码能核对数字、单位、期间、占位符语境和若干语义规则，并拒绝不可见字符、链接与 HTML；但语义改写不可能穷举，不能保证 LLM 文字完全正确，周报与 Agent 文案都应作为待审草稿。
- **检索**：只用 BM25 关键字检索，没有向量检索，同义词敏感。
- **Agent 建议偏保守**：提示中已提供价值层级与折扣上限，7 个真实调用场景中提议优惠的从 0 个变为 1 个；模型仍常把“近 90 天未购买”误读为只能提醒，最终仍由规则引擎判定。
- **费用**：按 `.env` 中的单价估算，未与供应商账单核对。
- **人工复核**：周报的人工抽查尚未完成（AI-10）；其他评测都是自审或 AI 测试（GPT 盲测、Gemini 对抗测试、GPT 模拟用户测试），都不是人工测试。
- **并发与部署**：单机演示环境；草稿库为 SQLite 单文件；没有账号与权限体系。
- **推送**：周报没有定时推送；Agent 没有任何发送能力（有意不做）。
