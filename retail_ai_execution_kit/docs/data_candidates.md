## 2. 与时效条款的关系（只列事实，不判断是否合规）

课程原文有两处时效要求：“2026 年 1 月以后的数据集”和天池表中的“2025 年 6 月后”。原文没有说明按哪个时间判断（D001）。下表按三种可能的口径分别列出：

| 候选 | 按事件时间 | 按首次发布 | 按最近更新 |
|---|---|---|---|
| A UCI | 2009–2011，两条都不满足 | 2019，两条都不满足 | 页面没有显示 |
| B 合成包 | 模拟事件跨 2024–2026，其中一部分落在 2026 年以后，**但事件是模拟的，不是真实采集** | 2026-07，满足两条 | 2026-09，满足两条 |
| C Cosmetics | 2019–2020，两条都不满足 | 2019，两条都不满足 | 页面声明不再更新 |
| D T-ECD | 绝对日期无法确定 | 2025-09：满足“2025 年 6 月后”，不满足“2026 年 1 月以后” | 2026-10，满足两条 |

验收条件 3 的结论：

- A 和 C 都是 2020 年以前的真实历史数据，只有在教师认可“历史数据可用于方法验证”之后，才能正式采用（D001）。
- D 不能因为 2026 年有更新就认定合规：事件日期是相对编号，数据经过扰动，含有合成事件，而且体量过大。它只作为文献和背景候选。
- B 的生成与发布时间满足两条时效要求，但它是完全合成的数据。能否作为“原始数据 / 行业业务数据”是另一个问题（D006），也需要教师答复。

## 3. 合成包本地副本的来源核验（关键发现）

1. 本地 `../ecommerce-sample-database-100k/01_source/baseline_10000_seed42.zip`（SHA-256 `d50ee64a…7a16`，1,310,750 字节）与网站当前下载件（`068bd2d3…7fa3`，1,262,760 字节，与网站 manifest 中的哈希一致）**不是同一个 ZIP 文件**〔实测〕。
2. 把两个 ZIP 中的 14 个数据文件逐一比较，**SHA-256 全部相同**；两者的 `simulation_run_id` 都是 `simulation_run_20260721_003414_baseline_seed42`〔实测〕。差别只在压缩包外壳：本地 ZIP 多了 `__MACOSX/` 条目，说明它是在 macOS 上被重新打包的。结论：**本地数据内容就是网站发布的 baseline 样例**。
3. 许可：仓库 README 和 `data/sample_output/LICENSE-DATA` 写的是“*本目录中*附带的样例数据”采用 CC0。但该目录里的样例是另一次运行（`20260717_155231`，20,000 个客户，1,200 个卖家），不是我们使用的 `20260721` 这次（3,647 个客户，800 个卖家）。网站下载页没有许可文字，README 还写明“项目不对你自己生成的数据设定许可”〔页〕。因此，数据包自带 `DATA_SOURCE.md` 中“预生成样例使用 CC0 1.0”的说法**不能直接套用到这份文件**。
   - 对课程的影响：用于教学且不对外发布（C07），风险很低。但报告中应如实写：“网站下载件未标明许可；同作者仓库内的同类样例为 CC0；代码为 MIT”。如需确认，可以联系作者，这属于外发行为，需要用户决定。
4. 生成器声明：数据完全合成，“不得被解读为真实市场数据，也不得用于实际经营决策”〔页〕。本项目只能把它表述为教学模拟场景。
