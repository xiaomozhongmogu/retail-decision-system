## 2. 缓存与连接边界

| 检查 | 结果 |
|---|---|
| 视图查询缓存（`runtime._cached`）的键 | 发布版本 + 发布目录 + SQL（含视图、列与筛选）+ 绑定参数。同一查询命中缓存，换一个筛选是另一个条目；发布新版本后键自然失效 |
| 页面级缓存（本次新增） | 预测页的评分名单、客户页的生命周期汇总改用 `st.cache_data`，键为发布版本与目录。多次重跑、两个会话合计各只查询 1 次。原来每次页面重跑都会重新查库。`st.cache_data` 给每个会话返回副本，各会话不会改到同一份数据 |
| 数据库连接 | 每次查询单独打开只读连接，用完关闭，不在线程或会话之间共享连接。8 个线程同时查询，没有错误 |
| 页面不运行 ETL 或训练 | 五个页面渲染后，进程中没有加载任何导入、清洗、建仓、切分或训练模块，也没有加载 sklearn 或 lightgbm。模型页只读取冻结记录（`reports/model/*.json`）和发布版本中的评分表 |

## 3. 异常与恢复

| 场景 | 页面表现 |
|---|---|
| 没有已发布的数据版本 | 五个页面都显示空状态，并说明如何生成发布版本，不报错 |
| 发布目录损坏或文件缺失 | 显示空状态（外部测试 G-029，此前已修复） |
| 冻结的模型评估记录缺失或损坏（本次新增） | 预测页说明缺少哪些文件、如何重新生成，然后停止渲染；客户页只在“价值群”标签页提示，其余标签页照常显示。原来页面会直接报错崩溃 |
| 评分表的模型版本与冻结版本不一致（本次新增） | 不显示名单，说明版本不一致以及如何重新评分发布。原来页面不做检查 |
| LLM 接口不可达（用假密钥 + 无法连接的地址测试） | 查询仍按执行结果回答（47,590.59 USD）；要求“真实 LLM”的周报回退为通过数字复核的模板；Agent 仍生成待审草稿、未发送；页面上任何位置都不出现密钥 |
| 查询执行失败 | 显示“执行失败”和重试按钮，重试后正常回答（UI-06 检查） |

## 4. 已知限制

- 直接打开 `/data` 会弹出“Page not found”，然后显示首页（即数据口径页）。原因是该页是默认页，Streamlit 会忽略默认页的网址路径。从侧栏进入不受影响。
- 可读性只在浏览器视口模拟中检查（1280×720、400×900），没有在真实投影仪或手机上检查。对比度是目测，没有用工具测量。
- 页面级缓存保存在服务进程内，重启后重新读取。AI 工作台的结果仍只保存在浏览器会话中（外部测试 U-005，部分修复）。
