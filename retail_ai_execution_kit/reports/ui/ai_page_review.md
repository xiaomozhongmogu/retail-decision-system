## 1. 三个模块

| 标签页 | 用法 | 页面展示 |
|---|---|---|
| 查询助手 | 输入问题 → “待执行” → 执行 / 取消；出错时“重试”；可导出对话 JSON、清空会话 | 状态（已回答、需要澄清、不支持、没有数据、执行失败、已取消）、答案、结果表、LLM 口径提示（标明由 LLM 生成且不含数字）、“查询与证据”（SQL、后处理、期间、口径、as_of、数据版本、证据编号） |
| 经营周报 | 选择真实 LLM / 可信模板 / 回放 → 生成 | 生成模式、LLM 尝试次数与校验记录、最终数字复核结果、周报全文、引用、下载 Markdown；回放模式醒目提示“不是本次真实调用，不能作为在线调用的验收证据” |
| 挽回 Agent | 选客户，调整演示配置（同意、投诉、库存、近 30 天触达、已用预算）→ 运行 | 结束状态、用时、“未发送”、每一步的工具与结果、提议来源、规则判定与理由；草稿审核表（状态、已发送=否、文案来源），可通过、驳回、撤回 |

## 2. 不重复调用与会话隔离

- 所有结果存放在本浏览器会话的 session_state 中；页面重跑不会再次调用模型（检查中多次重跑后调用计数不变）。
- 查询要点“执行”才运行；周报要点“生成”才运行；Agent 对相同客户与配置第二次点击直接显示上次结果，草稿按请求编号幂等，不会重复创建。
- 另一个浏览器会话中的“那西部呢”不会使用第一个会话的上下文。
