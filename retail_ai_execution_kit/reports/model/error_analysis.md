## 3. 模型解释（不是因果）

标准化后绝对值最大的 10 个系数：

- products_90d: -0.2240
- categories_90d: +0.1544
- as_of_month: +0.1541
- delivered_count: +0.1498
- gap_last_days: -0.1384
- orders_all_time: -0.1046
- lines_per_order: +0.0761
- active_days_90d: -0.0752
- recency_days: -0.0604
- merch_all_time: -0.0581

系数只说明在这份数据里模型如何组合特征，**不表示改变某个特征就会改变复购**（例如“让客户多买几种商品”不会因此提高复购）。系数在特征相关时也不稳定。

## 4. 适用限制

- 测试期 74% 的客户也在训练期出现：结果只说明“已知客户在未来时点”的表现，不证明能推广到全新客户。
- 数据是一个合成生成器产生的美国式电商记录，生成器中复购与历史行为关系很弱；结论不能推广到真实企业，更不能推广到当代中国市场。
- 模型不估计营销触达的增量效果；没有实验数据，不能用风险分数代替“联系后能否挽回”。
- 由于个体区分力接近随机，页面与 Agent 只能展示平均复购水平和规则名单，并明确说明模型的这一限制。
