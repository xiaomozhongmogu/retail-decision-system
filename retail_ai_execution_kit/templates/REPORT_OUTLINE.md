# 报告、答辩与证据模板

本文件供各阶段写作与验收使用，**不是已经完成的报告**。所有结果、截图、运行记录、模型分数、成员贡献、教师意见和签名均须依据实际情况填写；不得把计划写成已完成事项。

课程依据：实验指导书第五部分“实验考核内容”、第六部分“实验进度安排”、附录“实验报告内容（填写模板）”，以及《智能决策综合实践选题报告》模板。不同阶段使用不同结构，不将选题报告五部分直接复制为最终报告。

## 使用规则

1. 报告中的数据定义、指标、标签、时间窗口和模型适用范围引用项目已确认的规格；发现冲突先记录，不在写报告时另定一套口径。
2. 前期报告可以写预期目标和拟定方法；中期及终期必须区分已完成、进行中、未完成和待确认。
3. 尚未执行的实验，其数值栏留空或标“未执行”，不使用示例成绩填充。真实执行失败也是可记录的结果。
4. 每个结论都关联真实查询、图表、模型输出或文献；相关性、预测和因果效果分别表述。
5. 所有证据使用可移交的项目相对路径，避免只有某个 AI 会话、某个人电脑或临时绝对路径能打开。
6. 课程原文要求设计方案提交为 Word 或 PDF。此 Markdown 是写作模板，正式提交前须按要求排版、导出并逐页检查。
7. 教师填写区和手写签名区保留空白，不由 AI 预填。模板中的姓名、班级、学号示例不构成真实成员信息。

## 五、10 分钟现场展示与 PPT 建议

这是项目建议节奏，非新增课程评分规则。课程原文要求 10 分钟现场演示及每人回答 1—2 个问题，未说明问答是否占这 10 分钟；以下按演示本身设计，另确认教师的现场安排。

| 用时 | PPT／现场内容 | 要展示的真实证据 |
| --- | --- | --- |
| 0:00—1:00 | 业务问题、数据来源与能力边界 | 数据事实和明确目标 |
| 1:00—2:30 | 数据准备与预处理 | 质量、退货／异常、计数金额核对 |
| 2:30—3:30 | 数仓与 OLAP | 表粒度、数据流、过滤和下钻 |
| 3:30—5:00 | 分群与预测 | 真实结果、时间切分、基线、适用母体 |
| 5:00—8:00 | 实际完成的 AI 模块 | 查询、报告、策略的输入输出和证据 |

| 数仓 | 为什么采用当前事实粒度，怎样证明维表关联没有放大金额？ | 去重客户数、客单价怎样在不同时间粒度重新计算？ |
| 模型 | 为什么不用随机拆分，怎样确保标签完整且特征没有泄漏？ | 风险高为什么不等于最值得优惠，模型对哪些客户不适用？ |
| AI | 生成 SQL 能执行为什么不等于正确或安全？ | 周报和营销草稿怎样证明数字、事实和规则有依据？ |
| 页面与集成 | 页面每次交互重跑时，为什么不应重新训练或全量 ETL？ | API 失败、无数据或数据更新时如何保证展示状态真实？ |
| 评估与文档 | 如何证明报告结果与交付代码、数据、模型一致？ | 哪项限制最影响结论，下一步应怎样验证？ |

每人还应能说明主题、数据来源、主链路及自己负责模块的输入输出。真实演练时间、问题和未掌握内容记录到团队文件，不填写模拟“通过”记录。
